## Trunk hotfix — add missing legal-hold migration to typed-failure test schema (PR #1022)

**Test-fixture fix** (implemented): restored a green `trunk-dev`. Two `db_handle_surface` tests in `autumn-harvest/tests/integration/typed_workflow_failure_tests.rs` failed their `assert!(matches!(err, HarvestError::WorkflowFailed { .. }))` assertion because `handle.result_raw()`/`result_snapshot()` on a sealed-`FAILED` execution returned `HarvestError::Database("column harvest_workflow_executions.legal_hold_set_at does not exist")` instead of the typed `WorkflowFailed`.

**Root cause**: the `db_handle_surface` tests build their testcontainers schema from a hand-rolled, ordered list of migration `up.sql` files (`INIT_SQL`) rather than running `diesel migration run`. That list omitted `20260709000001_harvest_legal_hold`, so the four `legal_hold_*` columns PR #1008 (issue #747, per-execution legal hold) added to the `WorkflowExecution` read struct were absent from the test schema — and once `WorkflowExecution::as_select()` began selecting them, loading any execution row against the stale schema errored. PR #1008 swept the `INIT_SQL` of many sibling test files to match but missed this file, which PR #995 (issue #767, typed workflow failures) had introduced only hours earlier.

**Fix**: adds the one missing migration to the `db_handle_surface::INIT_SQL` include list, in timestamp order (between `20260706000000_harvest_worker_sessions` and `20260710000002_harvest_workflow_continue_chain`). **Not a production regression** — a test-fixture omission only. No production code change, no new `WorkflowEvent` variant, no migration added or altered.

**Verification**: reproduced RED against a fresh local Postgres 16 (verbatim underlying error `Database("column harvest_workflow_executions.legal_hold_set_at does not exist")`); after the fix both tests pass. Full local CI mirror green — `cargo fmt --check`; `clippy -D warnings` across the crates/feature combos CI runs; `cargo test -p autumn-harvest --all-features --lib` = 1832 passed; no-DB integration target = 799 passed; classic-DAG lib = 1820 passed; the macros suite; the DB integration target compile-checked. CI runs the Docker-backed `typed_workflow_failure` suite on Linux.
