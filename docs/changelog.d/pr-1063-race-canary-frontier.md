## Phase 3.51 — Fix race-primitive canary replay false-positive on interleaved bookkeeping siblings (issue #1048)

A canary replay of an in-flight `wait_for_signal_timeout` (#476) or `spawn_child_workflow_timeout` (#779) race started concurrently with a bookkeeping side effect — e.g. `tokio::join!(race, async { ctx.side_effect(...) })` — incorrectly reported the run as `NonDeterminismDetected`, spuriously failing deploy-safety canary checks even though the workflow is fine and merely still parked on the race. Root cause: both race primitives carried a byte-identical inline "canary-frontier guard" that decided non-determinism from inside the race matcher by reading whether the cursor was at the frontier (`!has_non_lifecycle_unconsumed()`). But on an `InProgress` result the matcher **rewinds** the cursor to the interleaved sibling command so the sibling's own matcher can consume its event — so the guard read "not at frontier" (the sibling's `SideEffectRecorded` was momentarily unconsumed) and false-fired, poll-order-dependently, before the sibling future ran.

Fixed by deleting both inline guards in `context.rs` **symmetrically** (avoiding the twin↔sibling asymmetry the issue calls out) and deferring the `InProgress` decision to the executor's already-wired end-of-cycle authority: `history_has_unconsumed_events()` in `run_workflow_canary`, and `outcome_to_report`'s `Suspended` mapping for strict replay. That authority runs *after* all joined siblings have consumed their rewound events, so a clean parked race reads no unconsumed events (→ `ReplaySucceeded`) while a genuine leftover is still caught (→ `NonDeterminismDetected`). The `Diverged` arms are untouched — a real divergence always errors.

**Live-worker no-op:** the guards' load-bearing `return Err` was `strict_replay`-gated, so the live worker / crash-recovery replay (`strict_replay = false`) never executed it; the guard's `match_history` read that did run live was a redundant duplicate of the race matcher's own post-hook `pump_signal_handlers`, so its removal drops no signal-handler dispatch. **Diagnostic granularity:** a genuinely-parked race under strict `WorkflowReplayer` now surfaces the generic executor `NonDeterminismDetected` ("workflow suspended before all history events were replayed") rather than the old specific `SignalOrTimerResolved`/`ChildOrTimerResolved` message (status unchanged; no test asserted the old strings).

**No new `WorkflowEvent` variant, no migration, no production/live-worker behavior change.** Tests (all no-DB, `--features testing`, in `tests/integration/replayer_tests.rs`): AC1 canary-plus-interleaved-bookkeeping-sibling → `ReplaySucceeded` for both primitives (`signal_timeout_in_flight_with_bookkeeping_sibling_canary_replays_succeeded`, `child_timeout_in_flight_with_bookkeeping_sibling_canary_replays_succeeded`, both new red-first repros); AC2 strict-parked-race still errors (`signal_timeout_in_flight_strict_still_reports_nondeterminism`, `child_timeout_in_flight_strict_still_reports_nondeterminism`), genuine `Diverged` under canary still errors (`signal_timeout_genuine_divergence_still_detected_in_canary`, `child_timeout_genuine_divergence_still_detected_in_canary`), and the deferral does not blind canary to a genuine `InProgress` leftover (`signal_timeout_in_flight_genuine_leftover_event_still_detected_in_canary`, `child_timeout_in_flight_genuine_leftover_event_still_detected_in_canary`, both new); AC3 fixed symmetrically (both inline guards deleted identically, every test row present for both twins). Full local CI mirror green: fmt, clippy `--all-features --tests -D warnings` and `--no-default-features --features testing`, `--test integration` (949 passed), `--lib` (1563 passed).
